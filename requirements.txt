# 运行环境

本仓库在以下环境验证通过（Python 3.12 + CPU 即可跑推理；训练建议 GPU，CPU 也能跑）。

```
numpy>=1.24
scipy>=1.10
torch>=2.0
wfdb>=4.1          # 读取 WRIST / BIDMC 等 WFDB 格式
matplotlib>=3.6    # 出图
PyEMD>=1.0         # 仅经典 baseline 里的 EMD/EEMD 需要（缺失时该两行自动跳过）
```

安装：

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

实测版本：numpy 2.5.4 / scipy 1.18.1 / torch 2.14.1 / wfdb 4.3.1 / matplotlib 3.11.2 / PyEMD 1.10.0。

> 仅推理（软件接口）时只需要 `numpy scipy torch matplotlib`；
> `wfdb` 用于直接读原始数据集，`PyEMD` 仅用于经典 baseline 的 EMD 两行。
