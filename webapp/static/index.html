使用说明

          
本工作台是仓库软件接口 PPGDenoiser 的图形前端。后端调用训练好的 RLS + 残差 U-Net + 频域 CRM 集成模型，
            输出 ① 原波形 ② 伪影波形 M̂ ③ 滤净波形，并给出心率、质量指标和可下载产物。

          
1. 三步跑通

          
    
            
  • 选数据：左侧「演示数据」选场景，或「上传文件」选择 npz/csv/json。
    • 
            
  • 选模型：默认 lite（15.9 MB，测试 PRD 46.37）；复现最终数字选 full；仅 PPG 用 no_imu。
    • 
            
  • 开始处理：结果页可缩放三波形、查看心率曲线、下载 npz/json/csv/png。
    • 
          

          
2. 输入格式

          

            
格式必需 / 可选字段说明

            
NPZppg / acc gyro reference clean fs
              PPG 形状 (N,) 或 (n_lead,N)；ACC/Gyro 形状 (3,N)/(N,3)/(N,)；fs 标量。

            
CSVppg / acc_x,y,z gyro_x,y,z reference
              首行列名；CSV 不含采样率，必须在左侧填写 fs（例如 100 / 125 / 256）。

            
JSONppg / acc gyro reference fs
              数组形式；也可直接 POST 到 /api/denoise。

          

          
任意长度、任意采样率均可（内部重采样到 100 Hz）。>30 s 自动 30 s 窗 / 15 s 步进重叠相加；<1 s 拒绝；NaN 自动插值。

          
3. 输出怎么读

          
    
            
  • 心率中位：逐 8 s 窗心率的 median，异常窗更稳健。无 3 个以上窗时为 —。
    • 
            
  • 伪影占比：std(M̂)/std(PPG)。低于「静息旁路阈值」(默认 0.05) 时输出原波形，避免过度处理。
    • 
            
  • 输出 SNR：10·log10(var(clean)/var(PPG−clean))；旁路或残差≈0 时为 —。
    • 
            
  • 模式：imu = PPG+ACC+Gyro（最佳）；imu_acc = 仅 ACC；no_imu = 仅 PPG（伪影波形恒 0）。
    • 
          

          
4. 高级参数

          

            
参数默认作用

            
α0.40物理先验 PPG − α·M̂ 的收缩系数（CIME 标定）。

            
CRM 权重0.15时域残差集成与频域 CRM 的融合比例。

            
旁路阈值0.05伪影占比低于该值直接透传原波形。

            
taps / λ4 / 0.995RLS 参考时延与遗忘因子。

            
want_hr开关闭可显著加速（只出波形）。

          

          
5. REST API

          
# 健康检查
curl http://127.0.0.1:8000/api/health

# 演示数据
curl -X POST http://127.0.0.1:8000/api/denoise \
  -F source=demo -F scenario=moderate -F preset=lite -F want_hr=1

# 上传文件
curl -X POST http://127.0.0.1:8000/api/denoise \
  -F source=file -F file=@my.npz -F fs=100 -F preset=lite

# 纯 JSON（无需 IMU 时自动切换 no_imu）
curl -X POST http://127.0.0.1:8000/api/denoise \
  -H 'Content-Type: application/json' \
  -d '{"ppg":[0.1,0.2,...],"fs":100,"preset":"lite"}'

# 下载：/api/download/<run_id>/{npz,json,csv,png}
curl -OJ http://127.0.0.1:8000/api/download/<run_id>/npz

          
6. 已知边界

          
    
            
  • 强伪影（κ≫1）与中高强度腕部运动是主要失效区；八度/谐波锁定仅凭 PPG+IMU 不可修。
    • 
            
  • 波形真值仅 CIME 一个数据集；跨设备波形质量无法定量，只能用心率间接验证。
    • 
            
  • 演示信号为合成数据，PRD 不代表真实性能；真实 CIME 测试集 PRD 为 46.57（full）/ 46.37（lite）。
    •
