# PPG 运动伪影去除 · Web 工作台使用说明书

> 对应程序：`webapp/server.py` + `webapp/static/index.html`
> 对应算法接口：`scripts/modules/ppg_api.py` 的 `PPGDenoiser`
> 赛题：第十一届全国生物医学工程创新设计大赛 · 赛道三（PPG 运动伪影去除）
> **版本：v2.0**（2026-10-21）｜v1 原版已备份：本地 `webapp_原始版_v1备份_20261021/`、git tag `webapp-v1-original`

---

## 1. 这是什么

一个**本地网页工作台**，把仓库里的 PPG 去伪影算法完整包装成可视化应用：

- 输入：PPG（可选 ACC / Gyro），支持演示数据、`.npz`、`.csv`、`.json`；
- 处理：RLS 物理先验 → 残差 U-Net 集成 → 频域 CRM 融合 → 可靠性决策；
- 输出：**① 原波形 ② 伪影波形 M̂ ③ 滤净波形**、逐窗心率、质量指标；
- 交互：三波形缩放/平移/悬停读数、心率曲线、参考真值 PRD、历史记录；
- 导出：`.npz`（全量数组）、`.json`（元信息）、`.csv`（逐点波形）、`.png`（三波形图）。

后端必须运行，因为模型是 PyTorch 权重，不能直接在纯浏览器里推理。

## 3. 环境要求

- Python 3.10+（本机验证：Python 3.13）；
- `numpy`、`scipy`、`torch`、`matplotlib`、`flask`；
- 仓库根目录下存在训练好的权重：`models/ppg_denoise_v1/{lite,full,no_imu}/`；
- 仅 CPU 即可，无需 GPU。

安装依赖（在仓库根目录）：

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install flask
```

> `requirements.txt` 未显式列出 Flask；若已安装可跳过第二行。
> `wfdb`、`PyEMD` 只用于读取原始数据集 / 经典 baseline，网页推理不需要。

```bash

```

默认地址：<http://127.0.0.1:8000>


可选参数：

## 5. 界面使用

### 5.1 三步跑通

1. **选数据**
   - 「演示数据」：内置合成信号，零数据可用；
   - 「上传文件」：点击或拖拽 `.npz` / `.csv` / `.json`。
2. **选模型与参数**
   - 默认 `lite`（15.9 MB，测试 PRD 46.37，推荐）；
   - `full`（约 113 MB，41 残差 + 3 CRM，复现报告数字 46.57）；
   - `no_imu`（3 个单通道模型，仅 PPG 时使用）；
   - 无 ACC 时默认自动切换到 `no_imu`（可关闭勾选）。
3. **开始处理**
   - 结果页显示 6 个 KPI、三波形图、参考真值对比、输入摘要；
   - 心率 / 质量与导出 / 使用说明分别在顶部标签页。

### 5.2 演示场景（v2）

内置演示信号在 v2 中改为**真实 PPG 形态 + 物理幅度 IMU**（v1 是 3 个纯正弦叠加，属网络分布外输入）：

| 场景 | κ（伪影/脉搏） | 预期行为 |
|---|---|---|
| 静息 · 弱伪影 | 0.10 | **触发静息旁路**（输出 = 原波形）：演示"伪影过小时不做处理"的可靠性门控 |
| 中等运动 · 默认 | 1.0 | 伪影与脉搏同量级，三波形明显分离（最接近赛题主场景） |
| 强运动 · 边界 | 2.6 | 伪影远大于脉搏，观察方法失效边界 |

**演示态指标（重要）**：合成样例的 PRD 没有物理意义（参考不是真实 PPG 真值），
因此 v2 在演示数据下**不显示 PRD/Pearson/SNR**，改为显示「**链路自检**」：
输出长度一致 ✓、数值有限（无 NaN/Inf）✓、心率可用 ✓、伪影波形已估计 ✓、静息旁路状态 ✓、输出是否已改变 ✓。
上传**含 `reference` 的真实数据**后，自动恢复显示 PRD / Pearson / RMSE / SNR。

> 真实方法性能见 `实验最终报告.md`：CIME 1900 段 **PRD 103.41 → 46.57**（Pearson 0.9395 / SNR 7.78 dB）；
> 6 个公开域心率 MAE 1.06–16.03 bpm。

### 5.3 三波形图操作

| 操作 | 效果 |
|---|---|
| 滚轮 | 以鼠标位置为中心缩放时间轴 |
| 按住拖动 | 平移时间轴 |
| 双击 | 恢复全时段 |
| 悬停 | 显示该时刻各曲线数值 |
| 顶部图例按钮 | 显示/隐藏对应曲线（物理先验默认隐藏） |

颜色约定：

- 蓝色：① 原波形（含伪影）
- 红色：② 估计伪影 M̂
- 紫色：物理先验 `PPG − α·M̂`（默认隐藏）
- 绿色：③ 滤净波形（最终输出）
- 灰色虚线：参考真值（若输入带 `reference` / `clean`）

### 5.4 心率页

- 曲线：逐窗心率，8 s 窗 / 2 s 步进，Viterbi 全局路径；
- 橙色虚线：心率中位数；
- 统计：窗口数、中位、最小、最大、标准差；
- 信号短于 12 s（窗口数 < 3）或关闭 `want_hr` 时无心率。

### 5.5 质量与导出页

- `artifact_ratio`：`std(M̂)/std(PPG)`，低于阈值触发静息旁路；
- `bypass_applied`：是否旁路（输出 = 原波形）；
- `snr_improve_db`：输出信噪比；旁路或残差≈0 时为 `null`；**演示数据下界面显示「合成样例不适用」**；
- `mode`：`imu` / `imu_acc` / `no_imu`；
- `elapsed_s`、模型数量、α、CRM 权重、输入/输出点数；
- 下载按钮：NPZ / JSON / CSV / PNG；
- 「返回 JSON」与「API 调用示例」：可直接复制给软件同学或脚本。

## 6. 输入格式

### 6.1 NPZ（推荐）

```python
import numpy as np

np.savez_compressed(
    "my.npz",
    ppg=ppg,            # 必需，(N,) 或 (n_lead, N)
    acc=acc,            # 可选，(3,N) / (N,3) / (N,)
    gyro=gyro,          # 可选，同上；有则用 ACC_x + Gyro_y 异质参考
    reference=clean,    # 可选，干净 PPG 真值（也可用键 clean）
    fs=100.0,           # 可选，标量采样率
)
```

### 6.2 CSV

首行列名，至少包含 `ppg`：

```csv
ppg,acc_x,acc_y,acc_z,gyro_x,gyro_y,gyro_z,reference
0.123,0.01,0.02,0.03,0.001,0.002,0.003,0.100
...
```

- CSV 不含采样率，**必须在左侧填写 fs**（100 / 125 / 256 等）；
- 缺少 `reference` 列时不做 PRD 对比。

### 6.3 JSON

```json
{
  "ppg": [0.1, 0.2, 0.3],
  "acc": [[...], [...], [...]],
  "gyro": [[...], [...], [...]],
  "reference": [0.1, 0.2, 0.3],
  "fs": 100
}
```

也可以直接把该 JSON POST 到 `/api/denoise`。

### 6.4 通用约定

- **任意长度**：>30 s 自动 30 s 窗 + 15 s 步进 Hann 重叠相加；<30 s 反射填充；<1 s 拒绝；
- **任意采样率**：内部重采样到 100 Hz；25/50/64/125/256 Hz 均可；
- **NaN**：自动线性插值；常数/全零输入会被旁路或退化；
- **多导联 PPG**：自动取方差最大的一路；
- **ACC/Gyro**：支持 `(3,N)`、`(N,3)`、`(N,)`；缺省走无 IMU 分支；
- 上传上限 **64 MB**，输入上限 **2,000,000 点**（约 5.5 小时 @100 Hz）。

## 7. 参数说明

| 参数 | 默认 | 范围 | 作用 |
|---|---|---|---|
| `preset` | `lite` | lite / full / no_imu | 模型组合 |
| `auto_no_imu` | 开 | 开 / 关 | 无 ACC 时自动切换单通道模型 |
| `fs` | 自动 | 0.5–10000 | 采样率；NPZ/JSON 可自带，CSV 必填 |
| `alpha` | 0.40 | 0–1.5 | 物理先验 `PPG − α·M̂` 的收缩系数 |
| `crm_weight` | 0.15 | 0–1 | 时域残差与频域 CRM 融合权重 |
| `bypass_ratio` | 0.05 | 0–1 | 伪影占比低于该值时直接透传原波形 |
| `taps` | 4 | 1–16 | RLS 参考时延抽头数 |
| `lam` | 0.995 | 0.8–1 | RLS 遗忘因子 |
| `want_hr` | 开 | 开 / 关 | 是否估计心率；关闭更快 |

> `alpha` / `taps` / `lam` 若权重 checkpoint 内记录了训练标定值，会以权重为准；
> `crm_weight` / `bypass_ratio` 始终按请求参数生效。

## 8. 输出字段

### 8.1 网页 KPI

> 演示数据下：**输出 SNR 显示「—（合成样例不适用）」**；参考指标区显示「链路自检」而非 PRD。
> 上传真实数据（含 `reference`）后全部恢复。

| 指标 | 含义 |
|---|---|
| 心率中位 | 逐窗心率 median（bpm），可能为空 |
| 伪影占比 | `std(M̂)/std(PPG)` |
| 静息旁路 | 是否触发直接透传 |
| 输出 SNR | `10·log10(var(clean)/var(PPG−clean))` |
| 运行模式 | `imu` / `imu_acc` / `no_imu` |
| 处理耗时 | 模型推理耗时（不含上传/绘图） |

### 8.2 下载文件

| 格式 | 内容 |
|---|---|
| `*.npz` | `t`、`ppg_raw`、`artifact`、`ppg_prior`、`ppg_clean`、`hr_bpm`、`hr_t`、`reference`（如有） |
| `*.json` | `meta`、`quality`、`hr_median`、`hr_bpm`、输入摘要、参考指标 |
| `*_waveforms.csv` | 逐采样点：`t, ppg_raw, artifact, ppg_prior, ppg_clean[, reference]`（UTF-8 BOM，Excel 可直接打开） |
| `*_waveforms.png` | 服务端 matplotlib 渲染的三波形图（英文坐标，避免字体缺失） |

### 8.3 参考指标

输入带 `reference` / `clean` 时计算：

- **PRD**：`100·‖pred−ref‖/‖ref‖`，越小越好；
- **Pearson**：相关系数；
- **RMSE**：均方根误差；
- **SNR**：`10·log10(var(ref)/var(pred−ref))`。

参考波形会重采样并对齐到输出的 100 Hz 长度。

## 10. 故障排查

| 现象 | 原因 / 解决 |
|---|---|
| 页面显示「后端未连接」 | 未启动 `server.py`，或端口不对；检查终端日志 |
| `Address already in use` | 端口被占用：`--port 8010` 换端口 |
| `ModuleNotFoundError: flask` | `pip install flask` |
| `ModuleNotFoundError: torch` | 按 `requirements.txt` 安装，或 `pip install torch` |
| 上传 CSV 报「未提供采样率」 | CSV 不含 fs，在左侧填写采样率 |
| npz 报「缺少 ppg 键」 | 确认键名为 `ppg`（大小写不敏感），不要传特征文件 |
| 无 ACC 时没有伪影波形 | 正常：`no_imu` 模式 `artifact` 恒为 0 |
| 旁路导致输出=原波形 | `artifact_ratio < bypass_ratio`，可调低阈值或换数据 |
| `full` 首次加载慢 / 内存高 | 113 MB 权重，首次约 1–3 s；内存不足改用 `lite` |
| 下载 404 | 结果缓存最多 12 条且重启即清空；重新处理即可 |
| 中文图例显示方框 | 网页内为浏览器字体，正常；PNG 采用英文坐标规避该问题 |

## 11. 性能与限制

- 30 s 信号 CPU 推理约 **0.1–0.3 s**；5 min 约 1–2 s；内存 < 1 GB；
- 推理确定性：同输入逐位一致；
- 主要失效区：**强伪影（κ≫1）** 与 **中高强度腕部运动**；
- 八度/谐波锁定：仅凭 PPG+IMU 不可修，需要第二模态；
- 波形真值仅 CIME 一个数据集，跨设备波形质量无法定量；
- Web 服务使用 Flask 开发服务器，适合本地演示；对外部署请使用 gunicorn / waitress 等 WSGI 服务器。
